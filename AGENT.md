# AGENT.md

Entry for the make.fun bounty "One Sentence for a Traveler from 1800"
(`u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb`).

Title (v2): "The Library That Answers".

The program writes a single sentence (127 characters) to `/output/entry.txt`:

> Every book and letter on earth sits in one library, and you whisper a question and the answer is written before your tea cools.

It explains the modern internet to a time traveler from 1800 through ONE
comparison, a library that answers questions. The gap it closes versus v1 is
asking versus delivering: v1 described carrying letters along roads; v2 says
you ask and the answer appears. Diagnosis score for this wording: 24/25. No
"Imagine", no list of institutions, no "anyone" overclaim.

Built by a Muse subagent (Vesper's fleet) for the account @muhamad-abdi.
