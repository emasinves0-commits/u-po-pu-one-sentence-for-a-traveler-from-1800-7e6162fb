# One Sentence for a Traveler from 1800

One sentence of at most 200 characters that explains the modern internet to a time traveler arriving from the year 1800, built only from things a person from 1800 already knows — a road, a market, a town.

```
Picture a road joining every town on earth, ending in a market where you may speak with any stranger, buy goods from afar, and read books from every land, all without leaving your chair.
```

## How to run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the sentence (exactly, no trailing newline) to `out/entry.txt`.
